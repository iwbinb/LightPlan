# 05 · 架构、数据与安全恢复

## 1. 技术选择

SwiftUI原生（最低iOS17设计基线），MapKit地点/底图，CoreLocation可选定位，StoreKit 2非消耗型购买，UserNotifications本地提醒，WidgetKit小/中组件。Foundation-only `LightPlanCore`与UI分离，Swift Package没有外部依赖。XcodeGen是开发工具，不进入App运行时。[S03–S07,S13]

构建与提交应使用当前受支持的Xcode/SDK；2026-04-28起Apple要求上传使用Xcode26或更新及相应SDK，检索时官方提交页已说明Xcode27。[S02] iOS17最低运行版本并不意味着可以用旧SDK提交。Codex必须记录本机实际版本，不假定某安装路径存在。

不采用WebView套壳，不需要Electron/Three.js/服务器渲染。Cloudflare只在需要正式隐私、帮助与展示站时使用静态部署；不为天文计算调用Workers。

## 2. 模块图

```
SwiftUI screens ── AppState / observable models
                 ├─ LightPlanCore (astronomy, LocalDay, plan, archive)
                 ├─ MapKit / optional CoreLocation
                 ├─ Local repository → Application Support (atomic)
                 ├─ PurchaseStore → StoreKit verified entitlements
                 ├─ ReminderService → UserNotifications
                 └─ AppGroup sanitized snapshot → WidgetKit
```

UI只派发意图与展示状态；耗时全日计算在后台任务完成，保留请求ID丢弃过时响应。时间轴单个位置更新不能触发全天重新采样。缓存key至少含坐标、目的地时区、民用日、算法版本，不用“城市名”当唯一key。

## 3. 已提供模型

- Coordinate：经纬有限值校验；解码也验证。
- Place：UUID、name、coordinate、timeZoneID、isExample；时区不允许不存在。
- DaySummary：目的地日start/end、事件数组、窗口、horizonState；派生数据可重建。
- ShootPlan：稳定UUID、title、Place快照、日期、目标、准备/提醒分钟、created/updated。
- Archive：schemaVersion=1、places、plans；ISO8601日期、尺寸/条目上限、重复ID检查。

提醒执行状态应该与用户意图分离：用户设定“开提醒”不表示系统已成功安排。正式数据层还需增加NotificationState、最近安排时间与错误分类；备份默认包含意图但不包含系统授权或已排队通知的断言。

## 4. 存储与事务

计划/收藏写入Application Support文件，用原子替换和系统数据保护。设置仅存轻量语言/选点。不能把已付款布尔值写Defaults后当永久权益。共享组只放Widget必需地点、时区、语言与可用状态，不复制整份历史计划。

当前基础代码保存/删除已有回滚策略；文件损坏后锁定写入，并可原样导出损坏文件。正式版实现导入时：预检→冲突预览→用户确认→生成回滚备份→原子写→重新加载验证→只在成功后切换内存。失败不污染内存和磁盘。

建议默认档案限5MB、每类10,000条，避免意外内存峰值。限制是产品安全值，不是性能已测结论。大文件显示拒绝原因，不尝试无限解码。

## 5. 导入导出

导出是JSON便携备份，不上传到我们服务器；通过系统分享面板由用户自己选目的地。系统分享可能发往第三方，这是用户触发行为，隐私说明要准确。

导入支持当前schema；未来schema明确拒绝，旧schema经迁移后保留备份。重复ID不自动覆盖；默认保留本地并可选择导入为副本。名称、经纬、时区、日期、枚举、分钟范围逐项校验，不接受非有限浮点、未知事件、过大字符串或任意文件路径。

首次导入成功后不自动请求定位、不恢复过期提醒。让用户选择要启用的未来计划，统一说明系统权限。

## 6. 异步与并发

MainActor负责UI，Core纯值Sendable。各搜索请求带取消与序列号，旧结果不得覆盖新查询。切换地点日期时保留当前选点直到新数据可用；错误返回解释并允许重试。

现有Swift文件只做过Linux语法解析，未经Apple SDK类型检查。Mac阶段重点检查CoreLocation代理隔离、MapKit对象跨actor、StoreKit任务生命周期、Widget扩展API安全与ResourceBundle。必要时缩窄隔离边界，不能滥用`@unchecked Sendable`消除警告。

## 7. 配置

候选Bundle ID：org.nodestake.lightplan；App Group：group.org.nodestake.lightplan；内购：org.nodestake.lightplan.lifetime。以上是候选，不代表已在开发者账号注册。`ios/Config/Local.xcconfig`覆盖真实ID/Team；不提交个人签名文件。

App Group名称从Info.plist由同一build setting注入，app与widget不能各自写死不同值。正式版要核验实际entitlements而不只看YAML。支持网址/隐私网址/产品ID在release config集中审核。

## 8. 不做的后台行为

无位置持续采集、无背景网络轮询、无AI云调用、无强制账号、无远程同步依赖。Apple地图/地理编码/商店请求仍可能联网，所以不能宣传“整个App没有任何网络数据流”。日志不得记录精确地点、用户计划正文或购买token。
