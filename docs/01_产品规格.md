# 01 · 产品规格

## 1. 定位与用户任务

工作名：LightPlan / 光迹。面向摄影、旅行、风景、人像、建筑拍摄者，把地点、日期与太阳/月亮几何位置转成可保存的拍摄安排。不是天气预报、观星导航、专业测绘或安全导航工具。

核心承诺：**提前了解太阳/月亮的方向和光线时段，安排一次拍摄。** 不使用“保证拍到最好光线”“知道站在哪里一定最佳”等无法验证的宣传语。

典型任务：用户为周末的一个地点选择日期，拖动时间判断太阳方位，选黄金时段，设置提前30分钟准备，保存计划并收到提醒。信息按目的地时区展示；用户在另一国家也不会把拍摄时间看成手机本地时间。

## 3. 首发与后续的边界

**首发承诺必须完成**上述19项；包内代码为开发基础，`codex/requirements.json`记录未完成部分，不能因为基础代码还没写就把承诺改为下一版。

**可选增强，不作为当前首发承诺**：AR天空叠加、Apple Watch应用、云同步、天气/云量、真实地形遮挡、建筑三维阴影、银河/星轨、路线与交通、社交机位库、自动人像曝光建议、分地区节假日。视觉中不能出现未实现天气数据。

WidgetKit和Apple Watch是不同产品能力，不能用Widget声称已提供手表App。iPad与Duo宽屏是同一套数据与核心，不是把手机截图放大。

## 4. 免费与买断

拟定价格：美国$2.99、中国¥18，均为商店配置目标，不是写死在客户端的实际价格。用产品 `displayPrice` 和当地商店适用信息显示。

免费：今天、当前或首次选择的基础地点、当日位置/方向/时间轴、当日双点构图与最佳对齐时刻、示例、帮助、阅读已有计划、导出备份、恢复购买。完整解锁：其他日期与多地点规划、创建与编辑计划、收藏集合、完整Widget、14天对齐机会搜索和推荐拍摄机位。免费用户首次可手动选择基础地点，不因拒绝定位而失去全部价值；重新定位今日基础地点允许，不设置暗黑模式诱导升级。

不在打开第一屏强制付费；先完成“看今天的光线”，用户选择未来日期或保存计划时说明解锁内容。关闭购买页回到原来的地点/日期草稿。取消购买不是错误，Pending不显示成功，产品未加载不显示编造价格。

权益失效后，已保存内容保持可读、可导出；用户可取消已有提醒。查看已保存计划中的历史计算属于阅读数据，不再二次付费。

## 5. 产品质量与商业验证

“便宜很多”不是减功能后宣称全能。先针对自己明确承诺的任务与竞品做真实设备对照；未实测的竞品特性不写成已经落后的事实。目标购买转化率、留存和销量都待实测，不在包内虚构。

不内置第三方分析SDK。初期通过TestFlight反馈、经同意的任务观察和商店聚合数据评估使用体验。若后续增加遥测，先修改数据清单/隐私文案，再开发。

## 6. 关键非功能门槛（目标，不是本次实测）

目标：最低支持设备正常操作无崩溃，冷启动P95≤2.5秒；缓存位置下首页结果P95≤500ms；拖动更新流畅，不在主线程计算全日轨迹；文字/控件触达与大字体合格。具体设备与采样方法见测试规格。达不到先优化，不把目标改写为已实现。
