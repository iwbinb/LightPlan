# 微动画与可访问性

| 动作 | 实现/时序 | 降级 |
|---|---|---|
| 按钮按下 | LPPressStyle，0.98缩放+透明度，140ms easeOut | Reduce Motion下只变透明度 |
| 相位标签切换 | LPPhaseLabel，180ms淡变 | Reduce Motion下直接替换 |
| 拖动时间轴 | 手指与selectedInstant直接绑定，立即更新光点/数值/射线 | 不使用弹簧追赶手指；VoiceOver每次±1分钟 |
| 黄金/蓝调边界 | 只在跨相位时触发轻selection反馈 | 不对每个像素振动，不循环触觉 |
| 数字变化 | monospacedDigit，避免宽度跳动；numericText可用 | 连续拖动优先即时响应，不能引入全页动画 |
| 卡片/页面导航 | SwiftUI原生导航转场 | 服从系统减少动态设置 |
| 展开/收起 | 调整Map旁边栏布局，复用同一Map位置和state | 不复制整套业务状态，不在折叠时重置日期 |

没有无限粒子、自动循环光晕或伪造3D反射；这些不增加规划价值却可能消耗电量。玻璃主要用在小型地图控制件；大段读数和计划使用实体底色。

必须进行实际检查：44pt触控目标、VoiceOver顺序、动态字体最大两档、德语长词、泰语上下标、弱视高对比、Reduce Transparency、Reduce Motion。照片上的文字使用独立遮罩；不能因为正常字号看起来漂亮就接受辅助字号不可读。

性能目标（待原生测量，不是已完成指标）：60Hz设备常用拖动维持流畅、无持续长任务；120Hz不承诺每帧重新算全天。用Instruments保存机型、系统、场景、采样时长与卡顿记录，不能只写“很流畅”。
