# 素材生产与裁切

ImageGen母图：`design/production/masters/coastal-light-imagegen-master.png`，1536×1024。生成ID记录在manifest。照片中不含按钮、标题、天文数值、地图、图标或水印。

首页`hero-coastal`使用完整母图；计划页`hero-sunset`使用母图右侧裁切，突出日落与剪影。两者属于同一原创场景的复用，不声称是两张不同目的地照片。文件导出仅涉及裁切、JPEG/WebP压缩；没有用程序绘画代替ImageGen照片。

| 用途 | 生产资源 | 原生资源 | 使用方法 |
|---|---|---|---|
| 首页Hero | hero-coastal.webp | hero-coastal.imageset | scaledToFill，黑色渐变遮罩，文字独立渲染 |
| 计划Hero | hero-sunset.webp | hero-sunset.imageset | 右侧暖色裁切，标题放左下暗部 |
| 地图相位卡 | 同计划素材 | hero-sunset | 66×58pt缩略图；只做氛围配图，不能当地图 |
| 宽屏侧栏 | 同计划素材 | hero-sunset | 185pt卡片，真实数据叠加 |

不将上述图片标为鼓浪屿、厦门、柏林或东京的实拍，不用于天气判断。产品界面提供九语“原创氛围图 · 非现场照片”说明。显示的是计算太阳位置，不代表照片拍摄时刻。不可因为日照算法算到夜间就声称此照片为当地实时日落。

必须保留母图供重新裁切。Asset Catalog中的单一高分辨率资源为设备独立解码；不能谎称存在更高分辨率细节。后续更大屏质检发现画质不足，应更高分辨率重新生成或调整图像占比，不做假高清。

母图和衍生图属于本项目生成素材；正式商业发布仍需由所有者按其实际适用的服务条款、品牌与第三方权利进行核对。图片没有经过目的地真实性认证。

本包不附送任何字体文件。界面使用系统字体/SF Symbols；浏览器仅用本机字体进行参考渲染。不要从此包导出或分发Apple字体。
