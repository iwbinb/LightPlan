# 09 · 测试、证据与发布门槛

## 1. 历史基础验证与当前证据

**初始交付包的历史基线**：Swift 6.2.1/Linux 核心构建与49个XCTest方法通过，其中一个测试遍历396组冻结独立位置参考；当时UI文件仅做语法解析，尚未做Apple SDK类型检查。这些描述只对应初始包，不是当前版本状态。

**当前证据入口**：构建、原生回归、资源数量和未完成发布条件统一见 `STATUS.md` 及其关联报告。本轮独立科学报告记录139项核心测试通过、31/31目的地民用日事件对照通过；详见 `tests/reports/astronomy-events-2026-09-22.md`。这些有限样本与本机测试不等同真机、远端CI或App Store发布验收。

## 2. 科学测试必须继续

扩大太阳/月亮位置网格和年份随机抽样；以固定随机种子与不可变参考版本保留预期。高纬、跨日、无升落、阈值相切、不同地平高度、月视半径是单独测试，不因位置测试通过而跳过。

求根残差只验证算法内部自洽，独立升落对照仍是必要条件。本轮31个民用日样本已使用独立求解器对照：305个太阳事件最大差14.562秒、43个月亮事件最大差22.625秒，保持原太阳≤60秒/月亮≤120秒目标且没有事件数量不匹配。模型、参考工具和证据见 `docs/04_天文与时间规范.md` 及上述科学报告。有限样本不构成1900..2100全球连续保证，实际折射、海拔、建筑/地形遮挡及现场可见时刻仍未由这些测试验证。

## 3. 数据与流程测试

计划创建/编辑/复制/删除、同名/跨日、无事件保存、提醒提前跨日、过去提醒拒绝、拒绝权限后保存、编辑重排失败、删除通知取消；存储写失败必须保留先前数据。

备份：空库、5000条、重复ID、无效时区、NaN/Infinity、缺字段、过长字符串、未知schema、截断JSON、超5MB；导入取消不变化，写盘中断后原件可恢复。离线和升级后仍可读取/导出；备注与构图快照完整保留。

## 4. 原生UI与设备

记录Xcode/SDK/OS/设备型号/构建号。iPhone最小支持屏幕、普通主流屏、大字体；iPad窄分屏和横屏；Duo模拟/真机证据必须分开。宽度变化过程中正在编辑计划，检查草稿、日期和地图状态不丢。

九语至少五主页面+现场简报/错误/通知/Widget；VoiceOver完成选地点、调时间、保存计划。泰语显示/输入公历与佛历不混算，德法按钮不截断。

地图测试中国大陆已知点、港澳、日本、欧洲、经度180附近；真实观察点与方向一致。没有网络时地图失败不能遮蔽离线天文信息。

## 5. 性能与能耗（目标）

| 项目 | 方法 | 发布目标 |
|---|---|---|
| 冷启动 | 最低支持真机20次Release测量，排除首次安装设置 | P95≤2.5s，无主线程长阻塞 |
| 今日计算 | 缓存地点，50次计算/切日 | P95≤500ms，数据切换状态明确 |
| 拖时间 | 60秒持续拖动，Instruments帧记录 | 不因整日重算卡顿；目标接近屏幕刷新预算 |
| 内存 | 主流程10分钟+反复换地点200次 | 无持续增长趋势；绝对预算记录实际设备 |
| 电池/后台 | 前后台各30分钟 | 不做无必要定位/定时网络/无限循环动画 |
| 大数据 | 5000计划+5000地点固定fixture | 可读可备份无崩溃，耗时上报，不虚报 |

## 6. 付费下载完整功能与通知

按2026-09-22用户决定验证付费下载模式，见收费文档。新装/升级/重启/TestFlight均直接使用完整功能，不依赖内购配置；无网络下验证已知坐标与时区的计划、天文计算及备份。App Store付费价格、销售地区和协议另做账号验收，TestFlight不证明真实扣费。通知至少测试前台/后台/锁屏、权限拒绝、跨时区、修改系统时间、过去目标、用户改变权限。

Widget系统决定刷新预算，不能测试一次准点就宣传秒级准时。[S07] 本地通知和Widget不能互相替代。

## 7. Release gates

`codex/release_gates.json`为发布阻塞清单。任何required项非passed，`scripts/release_preflight.py`必须非零退出。不得为“全部绿灯”把pending改成passed；每个passed应有证据路径和reviewer。

正式上架必须全部完成：原生编译、完整首发功能、科学事件QA、九语审校、设备/可访问性、付费下载与全功能离线、备份恢复、通知、真实隐私数据审计、真实网址/品牌/账号配置、最终人工验收。

## 8. 证据格式

每次测试保存：命令、工具版本、平台、开始时间、退出码、结果统计、失败案例和截图路径。失败不删除。浏览器原型图只能命名browser；语法解析日志只能命名syntax，不使用native_verified这种误导名称。
