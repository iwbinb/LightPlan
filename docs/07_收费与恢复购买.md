# 07 · 一次性买断与权益

## 1. 产品

非消耗型产品候选ID `com.arenovo.lightplan.lifetime`。美国$2.99、中国¥18是计划价格，实际价格与税费由App Store Connect和对应storefront提供。应用显示`Product.displayPrice`，不能按美元汇率换算人民币，也不能把一个地区旧价格写死在截图里。

不含订阅，不把小额买断附加无限服务器/AI承诺。不促使用户进入自行搭建的卡付款页面。StoreKit官方当前权益作为权威数据。[S06]

## 2. 免费/付费边界

查看今天基础地点与当日地图免费；首次手动选地点免费；当天双点构图、主体方位和当天最佳对齐时刻免费。未来日期、多地点规划、创建/修改计划、收藏集、完整Widget、14天太阳/月亮对齐机会搜索和推荐拍摄机位解锁。查看旧计划、导出原文件、读取备份和恢复购买不受付费墙限制。

用户点受限动作时记录intent，解锁成功后继续该动作。价格加载失败则重试或关闭；不能显示“已免费解锁”来绕过商品配置缺失。

## 3. 权益状态机

`loading` → 当前已验证权益 → `entitled` / `notEntitled`；商品状态与权益状态分开。购买结果：verified.success → 完成transaction后刷新权益；userCancelled → 静默回到页面；pending → 提示等待批准，不解锁；unverified → 不解锁并给恢复/重试说明；failure → 保留草稿、可重试。

监听Transaction.updates，审核revocationDate和产品ID。恢复入口主动调用AppStore.sync，然后重查currentEntitlements。不要在每次启动强制sync导致无必要认证弹窗。首次离线且无可验证权益不能凭本地布尔值解锁；已验证交易的离线可用性需在真机验证，不能人为销毁用户缓存权益。

不记录银行卡、账号密码、原始收据到自建后台。交易错误用户文案本地化，诊断只记录无个人数据的错误分类。

## 4. 商店测试

本地StoreKit配置可用于UI状态与流程，但不代表真实支付。`ios/StoreKit/README.md`给出配置步骤；若有`.storekit`需经Xcode打开与实际验证才标记可用。

必须完成：首次购买、已有购买、取消、Pending/Ask to Buy、无网络、商品不存在、未验证交易、恢复成功/无购买、退款/撤销、家庭共享（只有正式配置支持且验证后宣传）、重新安装、换设备、地区价格、购买页面退出再回来。

购买与数据独立：退款后不删除计划，允许查看/导出；已安排提醒的产品策略应公开一致，默认保留原计划提醒意图并允许关闭，不因退款静默大量清除用户安排。新建提醒需按权益规则。

## 5. 上架配置依赖

所有者确认Bundle/App ID与产品ID、银行税务及协议、商店定价、商品本地化和截图；这些并未由本包创建。Codex可完成代码和可复现本地测试，不得在缺授权时替用户签协议或提交审核。

正式版禁止demo premium开关、模拟成功交易、占位价格和死链。浏览器原型的解锁模拟只存在prototype目录，不引入iOS target。签名归档前用静态检查确认。
