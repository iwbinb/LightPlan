# LightPlan · v3 视觉生产总纲

本版目标：将已经选定的摄影场景 + 浮动信息卡 + 地图控制层 + 拍摄时间表，落实为可编辑素材、可运行的浏览器视觉参考和接入现有原生工程的 SwiftUI 源码。不是再提交一张宣传拼图。

## 交付分层

| 层 | 文件 | 事实边界 |
|---|---|---|
| 视觉方向 | design/reference/01_已提供的ImageGen界面参考_非实机.png | 最初选定的风格参考；地图/时间不是数据依据 |
| 原创素材 | design/production/masters + assets.manifest.json | 一张ImageGen原创海岸母图，导出首页和计划页两种裁切；不是两次独立创作、不是目的地实拍 |
| 可执行参考 | prototype-v3/index.html | 本地HTML/CSS/JS实际布局，支持交互；不是WebView成品或iOS截图 |
| 原生实现 | ios/LightPlan/Visual、Theme.swift、MapView.swift | 已接入RootView，资源已放Asset Catalog；还需要Mac/Xcode类型检查和真机验收 |
| 测试与验收 | scripts/v3、ios/LightPlanVisualUITests | 浏览器检查和核心测试本次已运行；原生截图工具已给出，尚未在Mac执行 |

## 不允许的降级

不得把照片区改回普通渐变空卡；不得把整张效果图放进Image或WebView充当UI；不得将生成的地图当作地理数据；不得以浏览器方向图替代正式MapKit；不得把地图、计划或其他复杂部分悄悄删掉；不得硬编码截图上的天文时间。

保留九语、低价一次性买断、iPhone/Duo/iPad、自主本地计算、Cloudflare按需部署，以及原包全部首发功能。v3仅抬高视觉交付门槛，不撤销原任务。

## 规范优先顺序

数据与可访问性正确性 → 完整产品规格 → v3组件/布局约束 → v3实际渲染参考 → 初始ImageGen气质参考。若图片中的时间、地理方向、文字长度或系统安全区与真实平台冲突，修正示例，不牺牲正确性。

“100%可实现”是工程选型目标：不依赖未知硬件API、需要真人手动操作的美术软件、付费素材服务、无限云AI或图中无法还原的光学效果。不是未经编译就宣称100%已经完成。
