# 09 · 测试、证据与发布门槛

## 1. 已实际执行

Swift6.2.1/Linux核心构建与49个XCTest方法通过；其中一个测试遍历396组冻结独立位置参考。独立oracle脚本也实际运行，报告含最大/平均角差。UI Swift文件仅进行语法解析，**未做Apple SDK类型检查**。其余包/浏览器检查结果以`tests/reports/`最终报告为准。

## 2. 科学测试必须继续

扩大太阳/月亮位置网格和年份随机抽样；以固定随机种子与不可变参考版本保留预期。高纬、跨日、无升落、阈值相切、不同地平高度、月视半径是单独测试，不因位置测试通过而跳过。

求根残差只验证算法内部自洽；还要独立对照升落时刻。名义太阳事件目标≤1分钟（同一折射/地平模型），月事件目标≤2分钟；这些是拟定验收目标，尚未完成外部事件验证。真实可见时刻不纳入同一精度承诺。

## 3. 数据与流程测试

计划创建/编辑/复制/删除、同名/跨日、无事件保存、提醒提前跨日、过去提醒拒绝、拒绝权限后保存、编辑重排失败、删除通知取消；存储写失败必须保留先前数据。

备份：空库、5000条、重复ID、无效时区、NaN/Infinity、缺字段、过长字符串、未知schema、截断JSON、超5MB；导入取消不变化，写盘中断后原件可恢复。权益失效仍可读导出。

## 4. 原生UI与设备

记录Xcode/SDK/OS/设备型号/构建号。iPhone最小支持屏幕、普通主流屏、大字体；iPad窄分屏和横屏；Duo模拟/真机证据必须分开。宽度变化过程中正在编辑计划，检查草稿、日期和地图状态不丢。

九语至少五主页面+购买/错误/通知/Widget；VoiceOver完成选地点、调时间、保存计划。泰语显示/输入公历与佛历不混算，德法按钮不截断。

地图测试中国大陆已知点、港澳、日本、欧洲、经度180附近；真实观察点与方向一致。没有网络时地图失败不能遮蔽离线天文信息。

## 5. 性能与能耗（目标）

| 项目 | 方法 | 发布目标 |
|---|---|---|
| 冷启动 | 最低支持真机20次Release测量，排除首次安装设置 | P95≤2.5s，无主线程长阻塞 |
| 今日计算 | 缓存地点，50次计算/切日 | P95≤500ms，数据切换状态明确 |
| 拖时间 | 60秒持续拖动，Instruments帧记录 | 不因整日重算卡顿；目标接近屏幕刷新预算 |
| 内存 | 主流程10分钟+反复换地点200次 | 无持续增长趋势；绝对预算记录实际设备 |
| 电池/后台 | 前后台各30分钟 | 不做无必要定位/定时网络/无限循环动画 |
| 大数据 | 5000计划+5000地点固定fixture | 可读可备份无崩溃，耗时上报，不虚报 |

## 6. StoreKit与通知

见收费文档完整矩阵。Apple沙盒证据和本地StoreKit配置分开报告；解锁成功、恢复、退款与重装都必须验证。通知至少测试前台/后台/锁屏、权限拒绝、跨时区、修改系统时间、过去目标、用户改变权限。

Widget系统决定刷新预算，不能测试一次准点就宣传秒级准时。[S07] 本地通知和Widget不能互相替代。

## 7. Release gates

`codex/release_gates.json`为发布阻塞清单。任何required项非passed，`scripts/validate_release.py`必须非零退出。不得为“全部绿灯”把pending改成passed；每个passed应有证据路径和reviewer。

正式上架必须全部完成：原生编译、完整首发功能、科学事件QA、九语审校、设备/可访问性、购买沙盒、备份恢复、通知、真实隐私数据审计、真实网址/品牌/账号配置、最终人工验收。

## 8. 证据格式

每次测试保存：命令、工具版本、平台、开始时间、退出码、结果统计、失败案例和截图路径。失败不删除。浏览器原型图只能命名browser；语法解析日志只能命名syntax，不使用native_verified这种误导名称。
