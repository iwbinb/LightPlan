# 03 · UI、组件、视觉资源与动画

## 1. 已选方向

参考 `design/reference/01_已提供的ImageGen界面参考_非实机.png`：浅色、清晰、摄影内容为主，地图页大面积内容、底部时间轴，计划页垂直里程碑。不得将烘焙文字的图片当作整个页面贴上去。参考中的照片不作为假实时天气或真实地点实拍证明。

正式UI采用SwiftUI原生文字、矢量图标、系统材质、程序化太阳曲线和MapKit底图。无权利清晰的地点照片时用原创渐变/曲线，不随机套用一张其他地点的日落照片。

系统新材质可在当前SDK正式支持且可用时使用；iOS17降级为Material。无需私有API、假玻璃截图或过量叠加玻璃。参考源见 [S03]、[S04]，版本门槛要由Mac工具链验证。

## 2. 设计令牌

正式可机读值见 `design/tokens.json`。浅背景#F6F7F9，主文字#182532，次级#5D6978；暖橙#DB741F用于太阳强调，蓝#3077B8用于蓝调。暗色采用系统背景和语义色，不简单整体反色。文本对比用实际背景验算；颜色不是状态的唯一编码。

8pt基础间距，页面左右16–20pt，卡片内16pt，组间16–24pt。正文17pt、辅助15pt、次要说明13pt起；关键时间28–40pt。数字等宽，不使用7–10pt密集参数。按钮最小可触区域44×44pt；表单标签自然换行，不能强制一行缩到不可读。

卡片圆角20pt、主容器28pt（设计目标，不是设备轮廓）；系统Sheet、Alert、DatePicker优先原生。SafeArea不硬编码状态栏、底部手势区域、摄像头缺口或折叠线。

## 3. 组件清单

| 组件 | 输入 | 正常与异常 |
|---|---|---|
| PlaceHeader | 名称、日期、时区、示例标记 | 长地名换行，示例始终可识别 |
| LightHero | 当前光线band、地点 | 程序化背景，不根据band捏造晴天 |
| EventTile | event、timeZone、locale | 时间为空写无事件；长标签2行；早/晚不同语义 |
| SunArc | 全日采样、选择位置 | 真正低于地平线曲线；极昼/夜比例合理 |
| LightTimeline | day.start/end、windows、selected | 23/25小时正确；滚动/步进/VoiceOver同等操作 |
| SkyMetric | 真北方位、高度、天体 | 附单位；天顶方位解释；近地平线误差说明 |
| MapDirection | 观察点、方位、horizon | 地下虚线；太阳/月亮用不同符号，不能只靠颜色 |
| PlanMilestone | event、timeZone、status | 到场与事件区别；日期跨界必须显示日期 |
| ReminderStatus | disabled/denied/scheduled等 | 单独说明保存成功和提醒状态 |
| PurchasePanel | StoreKit.Product与权益 | 无价格时加载/重试，不可伪造原价/倒计时 |
| EmptyState | context、nextAction | 一句原因+一个明确可操作入口 |
| ErrorBanner | localizedKey、retry | 不覆盖页面全部内容；保留输入和数据 |

## 4. 布局与宽屏

容器宽<600pt：单栏；600..759pt：优先宽单栏或横屏上下分配；≥760pt且非辅助功能大字号：地图+约280..360pt信息栏；≥1100pt：允许导航侧栏。这里是**设计断点**，不是iPhone Duo官方点尺寸。

双栏先确保地图有足够宽度，右栏可滚动。最大字号不强行双栏；允许堆叠或独立详情页。下方时间轴应在地图任务中持续可达，不放在需要滚动很远的位置。

## 5. 动画说明

| 操作 | 建议动画 | 减少动态效果 |
|---|---|---|
| 时间轴拖动 | 数值即时更新，方向线直接跟随；不每帧重新计算全天事件 | 相同功能，无惯性/跳动 |
| 日期/地点切换 | 120–200ms淡入数据；加载状态保留旧内容并标示计算中 | 直接替换 |
| 保存计划 | 短暂确认与轻触觉（设置可关） | 不使用烟花或大范围弹跳 |
| 展开/旋转 | 系统布局过渡；业务状态不重建 | 无额外自定义转场 |
| 背景太阳 | 静态或低频更新，不持续跑高负载粒子 | 静态 |

这些数值是实施起点，流畅度以目标设备测量。纯装饰动画不得影响读数。

## 6. 可访问性验收

VoiceOver读取顺序：地点/日期 → 光线时段 → 当前参数 → 时间轴操作 → 保存。所有地图关键信息必须有文字替代；无需拖图也能选择地点、时间。提高对比、减少透明度、深色模式、最大字号下功能不丢。

动态字体测试英文/德文/泰文至少各一次；泰文字形上/下标不被行高裁切。购买页、通知说明和警告不设固定高度。表单错误关联到相应字段，提交后聚焦首个错误。
