# 地点定位与地图样式修复 — 2026-09-23

用户在实体 iPhone 反馈：「地点」页缺少定位入口，地图无法明确切换影像与普通底图。本轮在 `dev` 的现有未提交工作基础上补齐入口与可见状态，没有更改已保存地点、计划或底图来源。

- 「地点」页提供「使用我的位置」：仅用户点击后调用系统定位授权；成功解析坐标和目的地时区后切到该地点的地图。GPS、地址或时区解析失败时，仍可手动填写地点；已有坐标可带入手动表单。离开页面时取消未完成的请求，避免旧结果改动当前地点。
- 地图保留原有 MapKit 影像和标准底图，切换按钮直接显示当前是「卫星影像」还是「普通地图」，点击切换并把选择保存在本机偏好中。按钮也提供当前模式的辅助功能值。
- 两个新增文案键同步九语；目录自动审计为 370 键、3330 条译文，零缺失。这只是完整性检查，不等于母语审校。
