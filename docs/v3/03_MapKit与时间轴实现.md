# 地图与时间轴工程规则

正式App只使用MapKit原生地图。浏览器离线参考中明确标记“方向预览·未加载地图底图”，这是可运行的控制层与方向投影参考，不是正式地图替代方案。本次尝试获取开放矢量底图未成功，因此没有伪造或嵌入来源不清的地图。无需用户申请另一个地图服务才能运行原生MapKit工程。

## 地图层

1. 前两版SwiftUI `Map(position:)`在真机切换时，即使重建视图并旁路设置MapKit配置，仍保留旧瓦片。当前由应用直接持有原生`MKMapView`，通过公开的`preferredConfiguration`与相容的`mapType`设置影像/普通底图；区域相机、天体射线和主体标记由同一MapKit视图更新。影像清晰度和覆盖由MapKit服务决定，地图联网不可保证离线可用。
2. 原点为实际拍摄地点。太阳/月亮方位都是相对真北顺时针；MapKit负责地图旋转投影，不直接把方位角当屏幕角。
3. MapPolyline绘制当前方位、升/落射线、地平线以上的日内轨迹。地下状态用虚线并说明，不因为太阳下山仍画实线宣称可见。
4. MapPolygon绘制傍晚黄金区间的角度扇区；这不是建筑物投影、不代表无遮挡视线。
5. Annotation是原生符号+时间标签。地图相机保持用户视角；拖动时间不能反复recenter。地点改变时才主动回中心。
6. 顶部搜索/日期和侧边图层/定位/收藏按钮是真控件。定位箭头经用户点击后请求设备GPS，并更新拍摄地点；地图可见期间用同一份CoreLocation坐标更新蓝点，拍摄机位另用相机图标标识，离开地图即停止持续定位。这样不依赖在本轮中国大陆模拟地图上与原始GPS相差数百米的MapKit系统位置坐标，也不手写地图坐标偏移补丁。长按定位箭头可回到已选拍摄地点。MapKit法律署名、比例尺与罗盘须在Mac验证位置；禁止覆盖版权标记。

## 数据与性能

`VisualSampler`按目的地实际民用日生成289个采样，覆盖23/24/25小时，不将一天写死86400秒。`MapProjection.make`预先生成太阳与月亮日内轨迹和黄金扇区，切换时间只计算当前读数与一条射线。负高度分段，不跨地下区间连一条穿越整图的轨迹。

太阳位置标签、地图射线和时间轴共享`state.selectedInstant`。不新增一个只改变屏幕时间而不影响几何的“UI时间”。

曲线阈值继承核心：黄金[-4°,6°]，蓝调[-6°,-4°]。它们是本产品约定的几何区间，不保证实际色温、云量、空气质量或照片质量。

## 必测边界

- 359°到1°的最短角差；日期线附近的坐标归一；纬度±90附近；月亮轨迹跨午夜分段。
- 时区/DST；当天结束点严格小于下一天开始，不重复00:00事件。
- 日期弹层取消不改变当前日期或保留过时summary。
- 地点切换取消/旧后台计算迟到，不覆盖新结果。
- 地图旋转后射线相对地理方向正确；样式切换后实际底图瓦片变化且相机位置稳定，定位箭头调用系统位置，长按回到已选地点。
- 中国大陆地图坐标与真实地点对应需实机/MapKit验证；不要手写网上的偏移补丁同时又让MapKit处理而导致二次偏移。

所有未在原生设备上执行的检查仍为pending，核心数值测试不能代替MapKit投影测试。
