# 01 · 产品规格

## 1. 定位与用户任务

工作名：LightPlan / 光迹。面向摄影、旅行、风景、人像、建筑拍摄者，把地点、日期与太阳/月亮几何位置转成可保存的拍摄安排。不是天气预报、观星导航、专业测绘或安全导航工具。

核心承诺：**提前了解太阳/月亮的方向和光线时段，安排一次拍摄。** 不使用“保证拍到最好光线”“知道站在哪里一定最佳”等无法验证的宣传语。

典型任务：用户为周末的一个地点选择日期，拖动时间判断太阳方位，选黄金时段，设置提前30分钟准备，保存计划并收到提醒。信息按目的地时区展示；用户在另一国家也不会把拍摄时间看成手机本地时间。

### 2026-09-22 · 摄影任务能力扩充

本轮围绕“选条件 → 比机会 → 看取景范围 → 保存安排 → 现场使用 → 留下可复用记录”扩充实现；下面的功能说明不代表真机、全部语言或付费意愿已经验收。

- **构图预演**：以观察点指向主体的方位为相机朝向，使用36 × 24mm等效画幅的直线投影针孔模型；等效焦距14–1200mm，横向3:2/竖向2:3，参考点仰角可调−30°…60°。根据所选时刻显示太阳/月亮在画面中的位置、视直径及在画内/部分入画/画外状态。参考仰角由用户提供；界面不是相机实景、AR或三维主体模型，不根据地图自动推断建筑高度，不模拟地形、折射、镜头畸变或现场遮挡。
- **连续机会时间窗**：可选起始日与1–90个目的地民用日；保留低空、太阳高度、全部候选预设，并可细调方位误差及天体高度。太阳高度可选不限、黄金角度−4°…6°、晨昏角度−6°…0°；月亮可选不限、明亮80–100%、暗月0–20%。每个结果说明起止、时长、最佳时刻、误差、高度及月亮照明比例；按日期或最佳匹配排序，最多展示60段，明确说明数量截断与日期范围截断。无结果不自动放宽条件。数值求根精度不等于真实可见时间的准确度。
- **项目与现场闭环**：计划可选最多60字符的项目名，按项目组织并搜索历史记录；“过去”依据事件时刻或目的地民用日，“已完成”是用户主动标记。现场模式倒计时至到场/拍摄时刻，显示保存的坐标、时区、备注和简报。倒计时反映计划，不代表天气或可见窗口；完成会关闭该计划提醒，重新打开不会自动启用旧提醒。
- **任务模板**：首页提供太阳/日落方向与月亮主体构图入口，预选天体、居中关系及搜索条件。太阳模板以0–6°低空、误差≤3°和14日范围起步；月亮模板以0–20°、误差≤3°、照明80–100%及30日范围起步。用户仍需选择自己的观察点和主体，再核对结果；模板不保证找到匹配，也不自动选择真实机位。太阳模板是低空角度预设，仍需从结果确认清晨或傍晚。

## 3. 首发与后续的边界

**首发承诺必须完成**上述19项；包内代码为开发基础，`codex/requirements.json`记录未完成部分，不能因为基础代码还没写就把承诺改为下一版。

**可选增强，不作为当前首发承诺**：AR天空叠加、Apple Watch应用、云同步、天气/云量、真实地形遮挡、建筑三维阴影、银河/星轨、路线与交通、社交机位库、自动人像曝光建议、分地区节假日。视觉中不能出现未实现天气数据。

WidgetKit和Apple Watch是不同产品能力，不能用Widget声称已提供手表App。iPad与Duo宽屏是同一套数据与核心，不是把手机截图放大。

## 4. 下载前付费（2026-09-22用户确认）

在App Store购买应用后下载，安装后全部功能可用，无应用内购买、无订阅、无应用账号。99美元是用户价值目标，不是定价；实际应用价格和销售地区由所有者在App Store Connect确认，不沿用旧内购价格假设。

日期、多地点、计划、收藏、Widget、构图机会和推荐机位没有免费/付费分层，不展示付费墙或恢复内购入口。首次打开完成“选地点→看今天的光线”，即可继续规划未来拍摄；定位拒绝与断网不触发功能授权限制。

本地数据与商店付款独立。重新下载由App Store处理；迁移用户计划需主动导出/导入，不能宣传未实现的云同步。离线能力仅覆盖已有坐标/时区的计算与计划管理，地图与地点搜索可能需要网络。

“便宜很多”不是减功能后宣称全能。先针对自己明确承诺的任务与竞品做真实设备对照；未实测的竞品特性不写成已经落后的事实。目标购买转化率、留存和销量都待实测，不在包内虚构。

不内置第三方分析SDK。初期通过TestFlight反馈、经同意的任务观察和商店聚合数据评估使用体验。若后续增加遥测，先修改数据清单/隐私文案，再开发。
