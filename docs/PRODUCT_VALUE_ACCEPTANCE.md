## 聚焦的任务

面向已有拍摄地点或明确主体的摄影用户，减少查方向、比日期、抄坐标和整理外拍安排的重复工作。一次任务应能从选机位和主体开始，筛选满足方位、高度与月亮照明条件的连续时间窗，预演镜头画幅内的天体位置与大小，保存可重启恢复的计划，再在现场读取简报、打开地图、查看倒计时及管理提醒。拍摄结束后按项目保留记录，后续可以搜索并复用。

低空与太阳高度窗口只描述几何条件；它们不预测天气、遮挡、道路可达或照片质量。全部候选允许查看最近结果，但不会隐藏弱匹配。用户可以手动输入主体坐标，无需精确点按地图。

## 对真实用户的验收脚本

邀请至少5位符合上述任务的摄影用户，在得到同意后独立操作；不要求其提交精确私有机位，也不自动上传任何使用数据。

1. 从自己的外拍目标出发，在没有指导的情况下选择太阳或月亮任务，再设定机位和主体；确认模板并没有替用户选择真实地点。
2. 调整起始日期和搜索日数，尝试光线/高度/月亮照明条件；解释一个连续窗口与其最佳点的区别，并辨认无匹配、弱匹配和被截断的结果。
3. 在构图预演中比较两个焦段和横竖画幅，调整参考仰角；说明它能估算什么、哪些实景条件仍不知道。不能把示意图误认成现场照片或自动测高。
4. 保存计划和项目名，退出重开，确认日期、目的地时区、主体、时刻、笔记、相机参数和搜索条件；按项目名和备注关键词找到同一条记录。
5. 打开现场模式，解释到场/拍摄倒计时与实际光线的边界；在真机核对提醒，不用系统排队状态替代送达。
6. 标记完成，确认该计划提醒已取消且进入已完成列表；恢复待拍后确认不会自动重新开启旧提醒。让用户说明何时会重新使用此项目记录。
7. 说明原本怎样完成这项任务、这次减少了哪些步骤、还有什么阻碍；比较关键任务耗时，而不是仅询问是否喜欢功能。
