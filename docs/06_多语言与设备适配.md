## 2. 本地化质量

时间统一按地点时区；12/24小时尊重系统/用户偏好，日期与数字用Locale格式化。角度保留°，小数按地区。用户输入坐标支持当地小数分隔符并明确经纬字段，不能把逗号解析成新的坐标。

句子避免直接拼接导致语序错误，涉及复数/数量使用Catalog变化或完整模板；通知包含地点与目的地时间，不裸写本地17:30。用户地点名与计划名不机器翻译，不对全字符串强制大写。

太阳高度/方位、黄金时段、蓝调、日出日落、拍摄计划、现场简报等术语维护词表。检查德法长文本、日语换行、韩语助词、泰语基线与佛历、葡语pt-PT表达。AppStore截图必须从对应语言真实UI生成，不能只翻标题。

当前App本地位置权限说明已生成九语`InfoPlist.strings`；正式AppStore描述、隐私与支持文案仍为待审草案，见`appstore/`。本地隐私说明不能只有英文才能读到。

## 3. iPhone Duo的证据边界

Apple官方2026-09-09发布信息显示iPhone Duo采用5.4英寸外屏与7.6英寸展开屏，计划2026-10-16开始预订、2026-10-23开售。[S01] 本包日期2026-09-17，不能声称已经完成上市真机折叠测试。

实现目标：实际可用容器窄→完整单栏；实际容器宽→地图与信息并排；无需硬编码“5.4英寸等于多少点”，也不发明铰链事件API。使用SwiftUI尺寸/安全区/系统场景响应，实际SDK与模拟器是否提供Duo档位由Codex检查。

模拟器不存在时以可变宽布局测试“宽窄适配”，但标明不是Duo硬件认证。最终发布报告应明确实际测试设备名称、OS版本、构建版本和是否实机。

## 4. 布局规则

- 手机竖屏：卡片自适应一/两列、地图上方地点、下方可达时间轴，计划垂直里程碑。
- 手机横屏：能完成任务优先；根据高度减少装饰Hero而非缩小文字。
- Duo展开/宽屏：地图为主、右侧参数和保存动作，时间轴与选择数据一一对应。
- iPad：允许侧栏；不同分屏窗口自动退回单栏，外接键盘可切日期与步进时间。
- Dynamic Type辅助功能档：允许回退单栏，警告/表单/按钮不截断。

折叠展开过程保留Place、日期、绝对时刻、太阳/月亮选择、地图视区、表单草稿和滚动位置。不能因容器变化重新初始化AppState。

## 5. 验收矩阵

最少宽度设计测试320/375/390/430/600/760/820/1024/1366pt，注意这只是测试容器，不是官方机型规格。每种语言至少验证首页、地图、计划、现场简报、错误；德语与泰语再跑最大字号；横屏、分屏、减少动画、深色模式独立抽样。

九语机器完整性测试通过不等于语言质量通过。母语审校缺失时保持发布门槛pending；浏览器截图通过不代替iOS系统字体、DatePicker、Alert、Widget和VoiceOver测试。
